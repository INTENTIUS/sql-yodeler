# Which scenario claims a changed path can affect, read by
# `npm run claims -- --affected [base]` (scenarios/affected.ts).
#
#   <glob>  <claim>...     the claims a change to a matching path can affect
#   <glob>  ALL            every claim
#   <glob>  -              no claim: nothing a claim runs or reads
#
# The first line whose glob matches a path wins, so a file goes before its
# directory. A path no line matches runs every claim. Globs are relative to
# the repository root: * is any run of characters but /, ** any run that
# may cross /, and a glob ending in / is everything under that directory.
#
# test/claim-paths.test.ts checks that every claim is named by some line
# other than ALL, that every file under src/ matches a line, that each file
# in scenarios/claims/ maps to the claims it defines, and that every line
# matches a file in the repository.
